# v10.0.0 release verification — 2026-10-09

## Scope
Major milestone release bundling:
- **Lossless Video Stream Copy (Passthrough mode)** via FFmpeg backend (`-c:v copy`), instantaneous container remuxing (MKV ↔ MP4), and audio-only transcoding without video re-encoding.
- **Enriched Media Telemetry & Bitrate Analysis**: extraction of stream video bitrates, container overall bitrates, MKV `BPS` tags, framerate, 8-bit/10-bit depth, audio sample rates, and subtitle codecs in both GUI cards and headless CLI.
- **Modal Dialog Palette & QSS Specificity Cascade Fix**: elimination of transparent/dark dialog bugs in Rosé Light and Crimson Dark themes, with dedicated scrollable Validation Report dialog.
- **Memory-Safe MP4 Atom Surgery ($O(1)$ RAM)**: streaming chunk updates for multi-gigabyte video files with 64-bit MP4 atom support and atomic temporary file swapping.
- **Smart Efficiency Guard & Bloat Prevention**: pre-flight analysis alerting users when re-encoding high-efficiency video (HEVC/AV1) with RF $\le 28$ risks file expansion, and flagging heavy audio tracks.
- **Fahhim Theming & 1-Click Toggle**: instant toolbar toggle between Crimson Dark and Rosé Light.
- **Researched Optimal Presets**: `av1_efficient` (SVT-AV1 10-bit), `hevc_optimal` (x265 10-bit with `no-sao` and `aq-mode=3`), and `nvenc_optimal`.
- **In-App CLI Reference**: GUI help dialog and headless batch CLI parity.
- **Hardened File & Queue Security**: `0700` directory and `0600` file permissions, atomic file persistence, and package validation during self-update.
