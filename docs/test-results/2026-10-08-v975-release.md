# v9.7.5 release verification — 2026-10-08

## Scope
Fix for the user-reported v9.7.4 bug: clicking **Refresh** in Tools & Encoders
**killed the whole app** (silent exit, no log entry). Root cause: freeing a
still-running `QThread` → Qt `qFatal("QThread: Destroyed while thread is still
running")` → `abort()`. Full analysis: `docs/test-results/2026-10-08-qthread-refresh-crash.md`.
