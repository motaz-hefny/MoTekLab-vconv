## بدء الاستخدام

### البدء السريع

**سير العمل في 30 ثانية:**

1. شغّل vconv: `python3 vconv.py`
2. انقر **➕ ملفات** أو **➕ مجلد** لإضافة ملفات الفيديو
3. اختر **الترميز** و **الجودة** (الإعدادات الافتراضية مناسبة لمعظم المستخدمين)
4. انقر **🚀 تحويل** وشاهد ملفاتك تُرمّز

**مثال خطوة بخطوة — تحويل فيلم:**

```
1. افتح vconv (الواجهة تفتح تلقائياً)
2. انقر "➕ مجلد" → اختر "/فيديو/أفلام/"
3. يجد التطبيق جميع ملفات .mkv و .mp4 (حتى 500 ملف)
4. اختر ترميز "x265" بجودة RF 23
5. اختر صيغة "MKV" لدعم الترجمات والمسارات الصوتية المتعددة
6. ضع وضع الترجمة على "copy" واللغة "ara"
7. انقر "🚀 تحويل"
8. أشرطة التقدم تظهر حالة الترميز لكل ملف
9. عند الانتهاء، تظهر الملفات الجديدة بجانب الأصلية بامتداد .mp4
```

### الإعداد الأولي

vconv يكتشف أجهزتك تلقائياً ويوصي بأفضل ترميز:

| الجهاز المکتشف | الترميز الموصى به | السبب |
|---|---|---|
| بطاقة NVIDIA | NVENC H.265 | أسرع ترميز، جودة جيدة، استخدام منخفض للمعالج |
| بطاقة Intel | QSV H.265 | استهلاك منخفض للطاقة، مناسب للحواسيب المحمولة |
| بطاقة AMD | AMF H.265 | توازن جيد بين السرعة والجودة |
| لا يوجد بطاقة رسوميات | x265 (CPU) | أفضل جودة، أفضل ضغط، أبطأ |

**ماذا يحدث في أول تشغيل:**
1. فحص التبعيات — التحقق من وجود HandBrakeCLI و ffprobe
2. الكشف عن الأجهزة يفحص وجود بطاقات NVIDIA/Intel/AMD
3. إنشاء ملف الإعدادات في `~/.config/vconv/vconv.conf`
4. تطبيق الإعدادات الافتراضية (RF 27, x265, MP4, نسخ الصوت)

**إذا كانت التبعيات مفقودة:**
```
⚠️  تبعيات مفقودة:
  - HandBrakeCLI: sudo apt-get install handbrake-cli
  - ffprobe: sudo apt-get install ffmpeg
```

### المتطلبات الأساسية

**مطلوب:**
- **HandBrakeCLI** — محرك الترميز الفعلي. ثبّته:
  ```bash
  sudo apt-get install handbrake-cli      # دبيان/أوبونتو
  sudo dnf install handbrake-cli           # فيدورا
  sudo pacman -S handbrake                 # أرش
  ```

- **Python 3.8+** مع **PyQt6**:
  ```bash
  pip install PyQt6
  ```

**موصى به:**
- **ffprobe** (مع ffmpeg) — لتحليل الملفات:
  ```bash
  sudo apt-get install ffmpeg
  ```

**اختياري:**
- **nvidia-smi** — لكتشف بطاقة NVIDIA
- **vainfo** — لكتشف بطاقة Intel/AMD
- **markdown** (حزمة Python) — لعرض دليل المساعدة بشكل صحيح:
  ```bash
  pip install markdown
  ```

## إضافة الملفات

### إضافة ملفات فردية (➕ ملفات)

يفتح متصفح ملفات لاختيار ملف فيديو واحد أو أكثر.

**الصيغ المدعومة:**
```
MKV, MP4, AVI, MOV, WebM, WMV, FLV, M4V, TS, M2TS, MTS, VOB
```

**مثال — إضافة حلقات محددة:**
```
1. انقر "➕ ملفات"
2. انتقل إلى /فيديو/مسلسل/الموسم1/
3. Ctrl+نقر لاختيار: الحلقة1.mkv, الحلقة3.mkv, الحلقة5.mkv
4. انقر "فتح"
5. تظهر الحلقات الثلاث فقط في قائمة الملفات
```

### إضافة مجلد (➕ مجلد)

مسح مجلد كامل بشكل متكرر للبحث عن ملفات الفيديو.

**كيف يعمل:**
- يبحث في جميع المجلدات الفرعية تلقائياً
- يجد جميع الملفات ذات الامتدادات المدعومة (بدون تمييز بين الأحرف الكبيرة والصغيرة)
- محدود بـ 500 ملف لكل مسح لمنع مشاكل الذاكرة
- المجلد الذي تختاره يصبح **جذر المصدر**

**مثال — إضافة موسم مسلسل:**
```
مجلد المصدر: /فيديو/مسلسلات/بريكينغ باد/الموسم1/
الملفات الموجودة: الحلقة1.mkv, الحلقة2.mkv, ..., الحلقة7.mkv
جذر المصدر: /فيديو/مسلسلات/بريكينغ باد/الموسم1/
```

### الحفاظ على هيكل المجلدات

**السلوك الافتراضي (نفس المصدر):**
الملفات تُرمّز في موقعها الأصلي:
```
قبل:  /فيديو/فيلم.mkv
بعد:  /فيديو/فيلم.mp4   (الملف الأصلي فيلم.mkv لم يتغير)
```

**مجلد مخصص مع الحفاظ على الهيكل:**
عند استخدام "مجلد مخصص" مع إلغاء تحديد "إخراج مسطح":
```
المصدر:     /فيديو/مسلسل/الموسم1/الحلقة1.mkv
جذر المصدر: /فيديو/مسلسل/
الإخراج:    /مخرج/مسلسل/الموسم1/الحلقة1.mp4
```

### إدارة قائمة الملفات

| الزر | وظيفته | متى تستخدمه |
|------|--------|-------------|
| **➕ ملفات** | إضافة ملفات فردية | عندما تريد ملفات محددة |
| **➕ مجلد** | إضافة مجلد كامل | لمواسم المسلسلات، مجموعات الأفلام |
| **❌ مسح** | إزالة جميع الملفات | عندما تريد البدء من جديد |
| **❌ إزالة** | إزالة الملفات المحددة فقط | عندما أخطأت في الاختيار |
| **📋 إضافة إلى القائمة** | نقل الملفات المحددة إلى قائمة الانتظار | عندما تريد المعالجة لاحقاً |

## إعدادات الترميز

### الترميزات المتاحة

| الترميز | النوع | السرعة | حجم الملف | الجودة | الأفضل لـ |
|---------|------|--------|-----------|---------|----------|
| **NVENC H.265** | NVIDIA | ⚡ سريع جداً | متوسط | جيدة | تسجيلات الألعاب |
| **NVENC H.264** | NVIDIA | ⚡ سريع جداً | كبير | مقبولة | التوافق الأقصى |
| **QSV H.265** | Intel | ⚡ سريع | متوسط | جيدة | توفير الطاقة |
| **QSV H.264** | Intel | ⚡ سريع | كبير | مقبولة | ترميز سريع H.264 |
| **AMF H.265** | AMD | ⚡ سريع | متوسط | جيدة | ترميز AMD |
| **AMF H.264** | AMD | ⚡ سريع | كبير | مقبولة | توافق AMD |
| **x265 (CPU)** | معالج | 🐢 بطيء | صغير | ممتازة | أرشفة، أفضل ضغط |
| **x264 (CPU)** | معالج | 🐢 متوسط | متوسط | رائعة | توافق عالمي |
| **SVT-AV1** | معالج | 🐢 بطيء جداً | صغير جداً | الأفضل | أصغر ملفات |

### تسريع الأجهزة

**GPU vs CPU: أيهما تختار؟**

| الحالة | الموصى به | لماذا؟ |
|--------|-----------|--------|
| أريد السرعة | NVENC/QSV/AMF | أسرع 3-5 مرات من المعالج |
| أريد أصغر ملف | x265 | أفضل ضغط، أصغر بنسبة 30-50% |
| أريد أفضل جودة | x265 (RF 18-20) | ترميز أكثر كفاءة |
| أنا على بطارية محمول | QSV | استهلاك أقل للطاقة |

### معلمات x264/x265 المخصصة

إعداداتك الشخصية المفضلة تُطبق تلقائياً على جميع ترميزات x264/x265:

```
cabac=1:ref=5:analyse=0x133:me=umh:subme=9:chroma-me=1:
deadzone-inter=21:deadzone-intra=11:b-adapt=2:rc-lookahead=60:
vbv-maxrate=10000:vbv-bufsize=10000:qpmax=69:bframes=5:direct=auto
```

## الجودة والإعدادات المسبقة

### مقياس الجودة (RF)

RF (عامل الجودة) هو التحكم الأساسي بالجودة. **القيمة الأقل = جودة أفضل، ملفات أكبر.**

| RF | الجودة البصرية | حجم الملف | الاستخدام |
|----|---------------|-----------|----------|
| **18-20** | ممتازة | كبير | أرشفة، أفضل جودة |
| **21-23** | رائعة | جيد | نسخ عالية الجودة |
| **24-27** | جيدة | متوسط | افتراضي — أفضل توازن |
| **28-30** | مقبولة | صغير | أجهزة محمولة |
| **31-35** | ضعيفة | صغير جداً | معاينة البث |

### الإعدادات المسبقة

| الإعداد | RF | الوصف | الأفضل لـ |
|---------|-----|-------|----------|
| **سريع** | 27 | ترميز سريع، حجم متوازن | مسودات، اختبار |
| **متوازن** | 25 | أفضل قليلاً من الافتراضي | الاستخدام اليومي |
| **جودة عالية** | 22 | تحسين كبير في الجودة | أفلام، فيديوهات مهمة |
| **أرشفة** | 20 | أفضل جودة للتخزين | الأرشفة طويلة المدى |
| **مسلسل تلفزيوني** | 24 | محسّن للتلفزيون | حلقات مسلسلات |

## خيارات الإخراج

### نفس المصدر (افتراضي)

الملفات تُرمّز في موقعها **الأصلي**. الملف الأصلي **لا يُستبدل أبداً**.

**اتفاقية التسمية:**
```
المصدر:  /فيديو/فيلم.mkv
الإخراج: /فيديو/فيلم.mp4       (المرة الأولى)
         /فيديو/فيلم_1.mp4     (إذا كان فيلم.mp4 موجوداً بالفعل)
```

### مجلد مخصص

جميع المخرجات تذهب إلى مجلد وجهة واحد.

**مع الحفاظ على الهيكل (افتراضي):**
```
المصدر:     /فيديو/مسلسل/الموسم1/الحلقة1.mkv
الإخراج:    /مخرج/الموسم1/الحلقة1.mp4
```

**من دون الحفاظ على الهيكل (مسطح):**
حدد "إخراج مسطح (تفريغ جميع الملفات في مجلد واحد)"
```
المصدر:     /فيديو/مسلسل/الموسم1/الحلقة1.mkv
الإخراج:    /مخرج/الحلقة1.mp4
```

### صيغ الإخراج

| الميزة | MP4 | MKV |
|--------|-----|-----|
| **التوافق** | ممتاز (جميع الأجهزة) | جيد (معظم المشغلات) |
| **مسارات صوت متعددة** | محدود (1-2 مسار) | نعم (غير محدود) |
| **ترجمات متعددة** | محدود | نعم (غير محدود) |
| **فصول** | نعم | نعم |
| **صوت بدون فقدان (FLAC)** | لا | نعم |

**متى تستخدم MP4:**
- الرفع إلى يوتيوب، وسائل التواصل الاجتماعي
- التشغيل على iPhone, PlayStation
- المشاركة مع مستخدمين غير تقنيين
- البث عبر الشبكة

**متى تستخدم MKV:**
- الأرشفة مع مسارات صوت متعددة (تعليق، لغات مختلفة)
- ترجمات بلغات متعددة
- صوت FLAC بدون فقدان
- مسلسلات أنمي مع ترجمات منسقة (ASS/SSA)

### خيارات ترميز الصوت

| الترميز | النوع | الجودة | الأفضل لـ |
|---------|------|--------|----------|

| **256 kbps** | ممتازة | ~112 MB | صوت عالي الدقة |
| **320 kbps** | الأفضل | ~140 MB | أقصى جودة MP3/AAC |

## الترجمة

### وضع الترجمة المضمنة

| الوضع | السلوك | الاستخدام |
|------|--------|----------|
| **نسخ** | الاحتفاظ بترجمات المصدر المطابقة لفلتر اللغة | تريد ترجمات بلغة محددة |
| **الكل** | الاحتفاظ بجميع الترجمات المضمنة | كل ترجمة محفوظة |
| **لا شيء** | إزالة جميع الترجمات من الإخراج | فيديو نظيف، بدون ترجمات |

**مهم:** HandBrakeCLI لا يتضمن الترجمات افتراضياً. يجب عليك اختيار "نسخ" أو "الكل" للاحتفاظ بها.

### فلتر اللغة

أدخل رموز ISO 639-2 مفصولة بفواصل:

| الرمز | اللغة | الرمز | اللغة |
|------|--------|------|--------|
| ara | العربية | eng | الإنجليزية |
| fre | الفرنسية | spa | الإسبانية |
| ger | الألمانية | ita | الإيطالية |

**الافتراضي:** `eng,ara` — يحتفظ بالترجمات الإنجليزية والعربية.

### حرق الترجمة

"حرق" يعني أن الترجمات تُرسم بشكل دائم في صورة الفيديو. **لا يمكن إيقاف تشغيلها.**

**متى تحرق الترجمات:**
- الترجمات الإجبارية (أجزاء اللغة الأجنبية في الأفلام)
- عندما تحتاج الترجمات على أجهزة لا تدعم الترجمات الناعمة

**القيود:**
- يمكن حرق مسار ترجمة واحد فقط في كل مرة
- الترجمات المحروقة تزيد حجم الملف قليلاً

### الترجمات الخارجية

**الصيغ المدعومة:** SRT, ASS, SSA, SUB, VTT

إ **ضافة الترجمات الخارجية:**
1. انقر **➕ إضافة** أسفل "الترجمات الخارجية"
2. اختر ملف ترجمة واحد أو أكثر
3. يظهر حوار: **"اختر لغة هذه الترجمات"**
4. اختر رمز اللغة الصحيح (مثلاً "ara" للعربية)
5. يظهر الملف في القائمة كـ `الترجمة.srt [ara]`

**مثال — إضافة ترجمة عربية لفيلم:**
```
1. أضف الفيلم: "الفيلم.mkv"
2. في قسم الترجمة:
   - الوضع: "نسخ" (احتفظ بالترجمات الإنجليزية المضمنة)
   - اللغات: "eng,ara"
3. أضف ترجمة خارجية:
   - انقر "➕ إضافة"
   - اختر "الترجمة_العربية.srt"
   - اختر اللغة: "ara"
   - القائمة تظهر: الترجمة_العربية.srt [ara]
4. حوّل ← الإخراج يحتوي على الترجمات المضمنة والخارجية معاً
```

**ترميز الأحرف للنصوص غير اللاتينية:**
الترجمات العربية والصينية واليابانية والكورية تُعالج تلقائياً باستخدام UTF-8.

## قائمة الانتظار

### الإضافة إلى قائمة الانتظار

**ثلاث طرق لإضافة الملفات إلى قائمة الانتظار:**

| الطريقة | كيف | النتيجة |
|--------|-----|---------|
| اختر صفوفاً + انقر إضافة | اختر ملفات في الجدول، انقر الزر | فقط الملفات المحددة تُضاف |
| انقر إضافة (بدون تحديد) | فقط انقر الزر | جميع الملفات تُضاف |

**سير العمل:**
```
1. أضف ملفات عبر "➕ ملفات" أو "➕ مجلد"
2. راجع الملفات في جدول الملفات
3. (اختياري) اختر ملفات محددة
4. انقر "📋 إضافة إلى القائمة"
5. انتقل إلى جدول القائمة لمراجعة المهام
6. انقر "▶ بدء القائمة" عندما تكون مستعداً
```

### عمليات قائمة الانتظار

| الزر | وظيفته | متى تستخدمه |
|------|--------|-------------|
| **▶ بدء القائمة** | معالجة جميع المهام المعلقة | مستعد للترميز |
| **❌ إزالة المحدد** | حذف الصفوف المحددة من القائمة | إزالة مهام غير مرغوب فيها |
| **🗑 مسح الكل** | حذف جميع المهام من القائمة | بدء من جديد |

### حالات القائمة

| الحالة | المعنى | ماذا تفعل |
|--------|--------|-----------|
| **معلق** | ينتظر المعالجة | سيُشغل عند بدء القائمة |
| **قيد التشغيل** | يُرمّز حالياً | انتظر حتى ينتهي |
| **مكتمل** | تم الترميز بنجاح | استمتع بملفك |
| **فشل** | حدث خطأ في الترميز | تحقق من رسالة الخطأ، أعد المحاولة |
| **ملغي** | تم الإيقاف يدوياً | ابدأ مرة أخرى إذا أردت |

## التقدم والمراقبة

### مؤشرات التقدم

vconv لديه **شريطا تقدم:**

```
[━━━━━━━━━━━━━━━━━━━━] الإجمالي: 3/10 ملفات    ← عدد الملفات المنجزة
[━━━━━━━━━━━━━━━━━━━━] الملف الحالي: 72%        ← نسبة تقدم الترميز الحالي
```

### ماذا يحدث عند إغلاق vconv أثناء الترميز؟

1. الترميز الحالي **يُنهى** (سيكون الملف غير مكتمل)
2. أي ملفات مكتملة آمنة
3. قائمة الانتظار محفوظة (المهام المعلقة تبقى)
4. عند التشغيل التالي، المهام المعلقة لا تزال في القائمة

## التحقق والتحليل

### التحقق من الملفات (✅ تحقق)

يفحص كل ملف في قائمتك بحثاً عن مشاكل محتملة قبل الترميز:

| الفحص | ما يكتشفه | إذا فشل |
|-------|-----------|---------|
| الملف موجود | ملف مفقود | خطأ "الملف غير موجود" |
| صلاحية القراءة | لا يمكن قراءة الملف | "لا توجد صلاحية قراءة" |
| الصيغة المدعومة | نوع ملف خاطئ | "نوع ملف غير مدعوم" |

### تحليل الملفات (📊 تحليل)

يشغل ffprobe على كل ملف ويعرض:

```
📄 الفيلم.2024.mkv
   🎬 H.265 1920x1080 | 8.5 GB | ⏱️ 02:15:30
   📝 ترجمات (3): [ara] العربية, [eng] الإنجليزية
```

## إدارة الإعدادات

### حفظ الإعدادات الافتراضية

1. اضبط جميع إعداداتك المفضلة (الترميز، الجودة، الصيغة، الصوت)
2. اذهب إلى **ملف → إعدادات → حفظ الحالي كافتراضي**
3. هذه الإعدادات ستحمّل كل مرة تشغل فيها vconv

### إعادة تعيين الإعدادات

**ملف → إعدادات → إعادة تعيين إلى الافتراضي**

يعيد كل شيء إلى إعدادات المصنع:
- الجودة → RF 27
- الترميز → تلقائي
- الصيغة → MP4
- الصوت → نسخ

### ملف الإعدادات

الموقع: `~/.config/vconv/vconv.conf`

```json
{
  "general": {
    "language": "ar",
    "theme": "dark"
  },
  "defaults": {
    "encoder": "auto",
    "quality": 27,
    "format": "mp4",
    "audio_encoder": "copy"
  }
}
```

### سجلات التشغيل

الموقع: `~/.config/vconv/logs/vconv.log`

سجل التشغيل يسجل:
- كل أمر ترميز
- جميع الأخطاء والتحذيرات
- نتائج كشف الأجهزة
- تغييرات الإعدادات

## واجهة سطر الأوامر

يمكن استخدام vconv بالكامل من الطرفية دون واجهة رسومية.

### الاستخدام الأساسي

```bash
# تحويل جميع الفيديوهات في المجلد الحالي
vconv --batch

# تحويل بإعدادات مخصصة
vconv --batch --encoder x265 --quality 23 --format mkv

# تحديد مجلدات الإدخال والإخراج
vconv --folder_in /فيديو --folder_out /مخرج --batch

# تحليل الفيديوهات دون تحويل
vconv --folder_in /فيديو --analyze

# تشغيل الواجهة الرسومية
vconv --gui

# عرض الإصدار
vconv --version
```

### جميع خيارات سطر الأوامر

| الخيار | الاختصار | الوصف | الإفتراضي |
|--------|---------|-------|----------|
| `--folder_in` | `-i` | مجلد الإدخال | المجلد الحالي |
| `--folder_out` | `-O` | مجلد الإخراج | نفس المصدر |
| `--gui` | `-g` | تشغيل الواجهة الرسومية | تلقائي |
| `--batch` | `-b` | وضع الدفعة (بدون تفاعل) | معطل |
| `--analyze` | `-a` | تحليل فقط | معطل |
| `--encoder` | `-e` | الترميز | تلقائي |
| `--quality` | `-q` | الجودة (0-51) | 27 |
| `--preset` | `-p` | إعداد مسبق | لا شيء |
| `--format` | `-f` | صيغة الإخراج | mp4 |
| `--audio_encoder` | `-ae` | ترميز الصوت | copy |
| `--audio_bitrate` | `-ab` | معدل بت الصوت | 128 |
| `--debug` | `-d` | تسجيل مفصّل | معطل |
| `--version` | `-v` | عرض الإصدار | — |

### أمثلة متقدمة

**1. تحويل مسلسل:**
```bash
cd "/mnt/مسلسلات/بريكينغ باد/الموسم1"
vconv --batch
# الفحص: جميع ملفات .mkv و .mp4
# الإخراج: في نفس المكان بصيغة .mp4
```

**2. مجموعة أفلام بجودة عالية:**
```bash
vconv -i /mnt/أفلام -O /mnt/أرشفة -q 20 -e x265 -f mkv --batch
# x265 جودة RF 20 - شبه مثالية
```

**3. ترميز سريع للجوال:**
```bash
vconv -i /فيديو -O /جوال -q 30 -e nvenc_h265 -f mp4 --batch
# ترميز سريع باستخدام بطاقة NVIDIA
# جودة مناسبة للجوال
```

## حل المشاكل

### المشاكل الشائعة والحلول

#### "HandBrakeCLI غير موجود"
```
✅ الحل: ثبّت HandBrakeCLI
sudo apt-get install handbrake-cli   # دبيان/أوبونتو
sudo dnf install handbrake-cli        # فيدورا
```

#### "ffprobe غير متوفر"
التحليل لن يعمل بدون ffprobe. الترميز لا يزال يعمل.
```
✅ الحل: ثبّت ffmpeg (يشمل ffprobe)
sudo apt-get install ffmpeg
```

#### لا توجد ملفات فيديو
```
الأسباب المحتملة:
  ❌ المجلد فارغ
  ❌ الملفات ذات امتدادات غير مدعومة
  ❌ صلاحية الوصول مرفوضة
  
✅ تحقق من:
  - امتدادات الملفات: .mkv .mp4 .avi .mov
  - صلاحيات المجلد
```

#### الترجمات لا تظهر في الإخراج
```
الأسباب المحتملة:
  ❌ وضع الترجمة مضبوط على "لا شيء"
  ❌ فلتر اللغة لا يطابق لغات ترجمة المصدر
  ❌ ملف SRT الخارجي ليس بترميز UTF-8
  
✅ الحل:
  1. اضبط وضع الترجمة على "نسخ" أو "الكل"
  2. فلتر اللغة: "ara" للعربية
  3. للملفات الخارجية: أضفها عبر قسم الترجمة
```

#### الترجمة العربية تظهر بأحرف مشوشة
```
⚠️ كانت هذه مشكلة معروفة في v9.0.0.
✅ تم الإصلاح في v9.2.0: ترميز UTF-8 أصبح تلقائياً.
إذا كنت لا تزال ترى المشكلة، تحقق من أن ملف SRT محفوظ بـ UTF-8:
  file -i الترجمة.srt
  # يجب أن يظهر: charset=utf-8
```

**عام:**
- الترميز باستخدام بطاقة الرسوميات أسرع 3-5 مرات من المعالج

## الأسئلة الشائعة

**س: هل vconv يستبدل ملفاتي الأصلية؟**
ج: لا. الملفات الأصلية لا تُلمس أبداً. ملفات الإخراج دائماً لها امتداد مختلف (.mp4/.mkv).

**س: هل يمكنني التحويل إلى مجلد مختلف؟**
ج: نعم. اختر "مجلد مخصص" واختر وجهتك. هيكل المجلد الأصلي محفوظ بشكل افتراضي.

**س: هل تسريع الأجهزة مدعوم؟**
ج: نعم. NVIDIA NVENC و Intel QSV و AMD AMF كلها مدعومة ومكتشفة تلقائياً.

**س: كيف أحافظ على الترجمات في الإخراج؟**
ج: اضبط وضع الترجمة على "نسخ" أو "الكل". أدخل رموز لغتك في فلتر اللغة.

**س: لماذا ملف الإخراج كبير جداً؟**
ج: قيم RF المنخفضة = ملفات أكبر. جرب RF 27-30 لملفات أصغر.

**س: هل يدعم vconv ترميز AV1؟**
ج: نعم، عبر ترميز `libsvtav1`. إنه أبطأ بكثير ولكنه ينتج أصغر الملفات بأفضل جودة.

**س: كيف أحدث vconv؟**
ج: اسحب أحدث إصدار من GitHub:
```bash
cd MoTekLab-vconv
git pull
python3 vconv.py --version
```
