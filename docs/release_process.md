# Release Process

> Always produce 3 artifacts: `.deb`, `.AppImage`, and source (auto).

## Steps

### 1. Update Version
Update version in:
- `vconv.py` (VERSION string)
- `ui/main_window.py` (window title + status bar)
- `docs/user_guide.md` (version line at top)
- `CHANGELOG.md` (add new version entry)

### 2. Commit & Tag
```bash
git add -A
git commit -m "vX.Y.Z: summary of changes"
git tag vX.Y.Z
git push origin main --tags
```

### 3. Build .deb Package
```bash
# Create build structure
mkdir -p /tmp/vconv-build/vconv_X.Y.Z_all/DEBIAN
mkdir -p /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/{core,ui,utils,docs,presets,locales,themes}
mkdir -p /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/bin
mkdir -p /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/share/applications
mkdir -p /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/share/doc/vconv

# Copy files
cp vconv.py /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/
cp -r core/*.py /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/core/
cp -r ui/*.py /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/ui/
cp -r utils/*.py /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/utils/
cp -r docs/*.md /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/docs/
cp -r presets/*.json /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/presets/
cp -r locales/*.json /tmp/vconv-build/vconv_X.Y.Z_all/opt/vconv/locales/
cp CHANGELOG.md README.md LICENSE \
   /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/share/doc/vconv/

# Create wrapper
cat > /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/bin/vconv << 'EOF'
#!/bin/sh
exec python3 /opt/vconv/vconv.py "$@"
EOF
chmod +x /tmp/vconv-build/vconv_X.Y.Z_all/usr/local/bin/vconv

# Create DEBIAN/control (update version)
cat > /tmp/vconv-build/vconv_X.Y.Z_all/DEBIAN/control << 'CONTROL'
Package: vconv
Version: X.Y.Z
Section: multimedia
Priority: optional
Architecture: all
Depends: python3 (>= 3.8), python3-pyqt6, handbrake-cli, ffmpeg
Maintainer: MoTekLab <motaz@moteklab.com>
Description: vconv - Video Converter powered by HandBrakeCLI & PyQt6
 A modern video conversion tool with PyQt6 GUI.
CONTROL

# Build
dpkg-deb --build /tmp/vconv-build/vconv_X.Y.Z_all /tmp/vconv-build/vconv_X.Y.Z_all.deb
```

### 4. Build AppImage
```bash
# Install tool
pip install pyinstaller

# Build standalone executable
pyinstaller --onefile --name vconv \
  --distpath /tmp/vconv-appimage \
  --workpath /tmp/vconv-build/pyibuild \
  --specpath /tmp/vconv-build \
  --add-data "core:core" --add-data "ui:ui" --add-data "utils:utils" \
  --add-data "docs:docs" --add-data "presets:presets" --add-data "locales:locales" \
  --hidden-import PyQt6 --hidden-import PyQt6.QtCore \
  --hidden-import PyQt6.QtGui --hidden-import PyQt6.QtWidgets \
  --hidden-import markdown \
  vconv.py

# Create AppDir
mkdir -p /tmp/vconv-build/vconv.AppDir
cp /tmp/vconv-appimage/vconv /tmp/vconv-build/vconv.AppDir/AppRun
chmod +x /tmp/vconv-build/vconv.AppDir/AppRun

cat > /tmp/vconv-build/vconv.AppDir/vconv.desktop << 'DESKTOP'
[Desktop Entry]
Name=vconv
Comment=Video Converter powered by HandBrakeCLI
Exec=AppRun
Icon=vconv
Terminal=false
Type=Application
Categories=AudioVideo;Video;
DESKTOP

cp vconv.png /tmp/vconv-build/vconv.AppDir/  # 256x256 icon

# Build AppImage
appimagetool --appimage-extract-and-run \
  /tmp/vconv-build/vconv.AppDir \
  /tmp/vconv-build/vconv-X.Y.Z-x86_64.AppImage
```

### 5. Create GitHub Release
```bash
gh release create vX.Y.Z \
  --title "vX.Y.Z — Title" \
  --notes "Release notes here..."

# Or via API:
python3 << 'PYEOF'
import urllib.request, json
# ... (see existing release script)
PYEOF
```

### 6. Upload Artifacts
```bash
# Upload .deb
gh release upload vX.Y.Z /tmp/vconv-build/vconv_X.Y.Z_all.deb

# Upload AppImage
gh release upload vX.Y.Z /tmp/vconv-build/vconv-X.Y.Z-x86_64.AppImage
```
